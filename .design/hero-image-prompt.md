## Before you accept a result — proofread this checklist

The name is unusual and this is where image models fail. Check every one:

- [ ] **AADHVIK** — spelled exactly, no "Aadhvick" / "Aadvik" / "Aadhavik"
- [ ] **5TH** — not 6th, and the jumpsuit number reads 5
- [ ] **CONIFOX** — not "Confiox" / "Conifax"
- [ ] **EH29 9ER** — postcode digits correct
- [ ] **15:30 - 17:00** — not 3:30 or garbled
- [ ] **29TH AUGUST** — correct date
- [ ] No duplicated or nonsense lettering anywhere in the background

Generate 3-4 variations and pick the cleanest. Text errors are far more common than art
errors.

## Fixing a near-miss

- Face isn't him -> "Keep everything else identical, but make the boy's face match the
  reference photo more closely — same hairline, rounder cheeks."
- One word misspelled -> "Regenerate identical, but spell the headline exactly: AADHVIK'S 5TH"
- Too cluttered -> "Simplify the background, fewer elements, more open sky."

## If a tool refuses

The prompt describes the cars by colour, number and personality rather than naming
Lightning McQueen / Jackson Storm / Cruz Ramirez, because most image tools decline prompts
naming Disney/Pixar characters. If one still balks, drop the racing numbers (95 / 2.0 / 51)
and keep only the colour descriptions.
